# Areas of Mimer

Mimer is split into areas. Every change says which areas it touches before it is built (the change plan), and `pnpm areas report` lists the files that were changed, area by area, afterwards. A file belongs to the area with the longest matching path below (a path ending in `.` is a file and its tests: `src/lib/meeting.` is `meeting.ts` and `meeting.test.ts`). Every file in `src/` and `src-tauri/src/` must belong to one: `pnpm areas check` (part of `pnpm check`) fails on a file that does not.

**Shared** areas are used by all the others. A change to a shared area is a change everywhere (for example a new look for every text box). A feature area may use the shared areas but never another feature area's inside files; when two features need the same thing, it moves to a shared area.

The rules of an area are in the `CLAUDE.md` in its main folder.
