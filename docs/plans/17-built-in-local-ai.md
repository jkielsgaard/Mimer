> **Status: implemented in 0.8.0.** Run and tested on Linux with an AMD graphics card (Vulkan) with the Gemma 4 E2B and 12B files: waking took about 5 s, a request without the key is refused, tool calls work, Sleep and closing Mimer stop the engine. Windows, Nvidia, Intel and AMD-on-Windows use the same pinned release tables and flags but could not be run on this machine; the Windows-only code is compiled in CI and the NSIS hook was compiled with `makensis`.
>
> Differences from the text below: the CPU choice is only saved and shown (it does not change what is downloaded); thinking is controlled with `--reasoning off|on`, because Gemma's chat template asks the model to think unless it is off (`--reasoning-budget 0` did not stop it); the Gemma 4 files are Apache-2.0, not a separate licence.

# Feature 17 – A built-in local AI: Mimer without LM Studio

## What the user gets

- In **Settings → Built-in AI**: choose the **CPU** (AMD / Intel / other), the **GPU** (Nvidia / AMD / Intel / none) and a **model**, then **Download**. The engine and the model are downloaded once, checked against fixed checksums, and stored in Mimer's own folder.
- In the **Mimer tab**: a bar with **Wake Mimer** (loads the model into memory) and **Sleep Mimer** (unloads it and gives the memory back). The message box is **locked until Mimer is awake**.
- Settings for context size, GPU use, threads, flash attention, thinking and an automatic sleep after idle time.
- **Clear problems.** When something fails (not enough memory, no GPU driver, a missing Windows runtime, a port in use, a damaged download, …) the bar says what happened, what to do (numbered steps), and has the engine's own log under **Show details** with a Copy button.
- The model is gone when the engine process is: sleeping, closing Mimer, or **Mimer crashing** all stop it, so it never holds on to memory.
- Uninstalling Mimer on Windows removes the downloaded engine and models.

## Decisions (already made – do not change)

| Question                   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Engine                     | `llama-server` from **llama.cpp**, a fixed release (**b11636**), started by Mimer as a hidden background process. It speaks the OpenAI-compatible API Mimer already uses, so the built-in AI is one more provider kind, `builtin` (id `builtin`, name "Mimer (built-in)"). Nothing in the chat code changes.                                                                                                                                                                                                                                                                                                       |
| Engine download            | **Not** inside the installer (it would make it 20–600 MB larger and platform-specific). Downloaded at the user's request from the llama.cpp GitHub release, with the **SHA-256 and size of every file pinned in the code** (`engine/catalog.rs`). A mismatch deletes the file and shows an error.                                                                                                                                                                                                                                                                                                                  |
| Which engine file          | Windows and Linux (x64). **CPU**: the plain CPU build (picks the best instruction set itself). **Vulkan**: AMD, Intel and Nvidia GPUs (default for AMD and Intel). **CUDA 12** (+ its runtime): Nvidia (default for Nvidia, CUDA 13 as a choice). **ROCm**: AMD, and **SYCL**: Intel, both listed as "advanced". macOS and ARM are not supported.                                                                                                                                                                                                                                                                  |
| What the CPU choice does   | The CPU build is one download for AMD and Intel, so the choice does **not** change what is downloaded. It is saved and shown (detected automatically and pre-selected; the user can change it).                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Model                      | Downloaded from Hugging Face, pinned to a **commit** with the file's **SHA-256**: Gemma 4 QAT Q4_0 from Google (Apache-2.0, not gated): **12B** (recommended, 7.0 GB), **E4B** (5.2 GB, lighter), **E2B** (3.3 GB, very light), **26B-A4B** (14.4 GB, heavier, needs about 24 GB RAM). The user can add **their own `.gguf` file**, which is copied into Mimer's folder.                                                                                                                                                                                                                                           |
| Where files live           | A folder `mimer-ai` with `engine/`, `models/` and `logs/`. **Windows**: next to the program (`%LOCALAPPDATA%\Mimer\mimer-ai`, per-user install), so the uninstaller can remove it (an NSIS hook deletes the folder). If that folder cannot be written to, the user's app-data folder is used and the screen says so. **Linux**: an AppImage cannot write beside itself and a `.deb`/`.rpm` installs into a system folder, so the files go to the user's data folder (`~/.local/share/dk.mdvault.app/mimer-ai`); **Settings → Built-in AI → Remove files** deletes them. `pnpm tauri dev` uses the data folder too. |
| Safety                     | The server listens on `127.0.0.1` only, on a free port chosen at each wake, and needs a random **API key** made at each wake (kept in memory only, never on disk). Counts as local under the loopback rule (feature 16). The web UI is turned off. No extra command-line arguments can be entered.                                                                                                                                                                                                                                                                                                                 |
| Never leaves RAM behind    | The process is stopped by Sleep, by Mimer closing, and if Mimer is killed or crashes: Linux `PR_SET_PDEATHSIG`, Windows a **job object** with kill-on-close. A pid file also lets the next start remove a leftover `llama-server`.                                                                                                                                                                                                                                                                                                                                                                                 |
| Chat is locked until awake | In the UI (message box and Send disabled, with the reason) **and** in the backend (`engine::require_awake` returns an error that tells the user to press Wake Mimer). Only for the built-in provider; other providers are unchanged.                                                                                                                                                                                                                                                                                                                                                                               |
| Settings                   | `ai.builtin`: `cpu`, `gpu`, `backend`, `modelId`, `contextTokens` (default 16,384), `gpuLayers` (auto / all / CPU only / number), `threads` (0 = auto), `flashAttention` (auto/on/off), `thinking` (off by default), `idleSleepMinutes` (0 = never). Changes apply at the next wake. Schema version stays 1.                                                                                                                                                                                                                                                                                                       |
| Errors                     | `engine::diagnose` turns the exit code and the last log lines into a **title, numbered steps and details**. Known cases: out of memory (RAM or VRAM), Vulkan or CUDA driver problems, a missing DLL or shared library, a port in use, a damaged model, an engine too old for the model, permissions and security software, killed by the system. Unknown cases show the log.                                                                                                                                                                                                                                       |
| Embeddings                 | The built-in provider is not offered for semantic search (it runs a chat model).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Windows build check        | `ci.yml` also compiles the Rust code on Windows, because this code has Windows-only parts.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

## Tasks (as built)

1. **Backend `engine/`**: `hardware` (detect CPU, GPUs, RAM), `catalog` (pinned engine files and models), `paths`, `download` (resume, SHA-256, progress), `extract` (zip, tar.gz, safe paths), `process` (spawn, kill-on-parent-death, health wait, log), `diagnose`, `service` (install, wake, sleep, remove, idle timer, clean-up at start and exit).
2. **Settings and provider**: `ProviderKind::BuiltIn`, `ai.builtin`, normalisation, key lookup for the built-in provider, `require_awake` in the chat and inline paths.
3. **Commands and events**: `engine_hardware`, `engine_catalog`, `engine_status`, `engine_install`, `engine_cancel_install`, `engine_wake`, `engine_sleep`, `engine_remove`, `engine_add_model`; event `engine://status`.
4. **Frontend**: `engineStore`, **Settings → Built-in AI**, the **Wake/Sleep bar** and the locked message box in the Mimer tab, provider list and status bar.
5. **Installer**: NSIS hook that stops `llama-server` and deletes `mimer-ai` on uninstall.
6. **Tests and docs**: unit tests for everything that does not need a GPU, an ignored end-to-end test with the real engine and model, manual tests (including the hardware combinations that could not be run here), help topic, README, changelog, decisions.

## Not tested here (marked in the manual tests)

Windows (all of it), Nvidia/CUDA, Intel (Vulkan and SYCL), AMD ROCm, AMD and Intel CPUs on Windows. The pinned files and flags are the same for all of them, and the Windows-only code is compiled in CI.
