# Widget

A block of the start page (`src/features/start`): `card`, `radius-xl`, `space-4` padding, a `section-label` title. Half or full width in a two-column grid, one column under 640px.

- **Customize** puts every widget in arranging mode: dashed `primary` border, arrows always shown, Half | Full, and a cross. **Add widget** lists the ones not on the page; **Reset** goes back to Continue, Recent and Pinned.
- A widget shows only the person's own data and an empty state that says what will appear.
- A widget that needs AI says why it is off instead of disappearing.
