# CaptureBox

One box per kind of thing written down (`src/features/capture/CaptureBox.tsx`): **Quick note**, **New task** or **New idea**, each with its own title, help line and save button. There is never a choice of kind inside the box.

- From an entry that names the kind (New → Task): only that box, in the dialog.
- Ctrl/Cmd+Shift+N: "Write down a…" with T, I and N first.
- Where there is room to write without leaving (a meeting, Focus, the start page): `CapturePicker`, three buttons + Task, + Idea, + Quick note; the box stays open for the next one.
- A task always says **Into**: the meeting's or Focus' epic there, else the one used last.
