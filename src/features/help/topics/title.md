## Naming a note

Every new note is named when you make it, the same way everywhere.

1. Press **Ctrl/Cmd+N**, choose **New → Note** above the file tree, or right-click a folder and choose **New note**.
2. A small window asks for the **name**. It starts with `Untitled`, or `Untitled 1` and so on if that is taken.
3. Press **Create**. The note opens with the name as its first line, `# Weekly sync`, and the file is called `Weekly sync.md`.

## Names that are taken

In one folder, no two things may have the same name. Upper and lower case do not count, and a note counts without `.md`, so `Plan` and `plan` are the same, and so are a note `Plan` and a folder `Plan`. They would look the same in the file tree.

If the name is taken, the window says so in red while you type, tells what already has that name and where, and does not let you press **Create**. The same goes for new folders, renaming, and projects (two projects cannot have the same name).

If you move something to a folder that already has something with that name, Mimer stops and tells you in a window you have to close. Nothing is changed. Rename one of them and try again.

## Good to know

- Names Windows and OneDrive cannot keep are not accepted, and a red box says why: the characters `\ / : * ? " < > |`, a dot at the end (`PAM div.`), and names Windows keeps for itself such as `CON`, `NUL` or `COM1`.
- Notes made from a template (meeting notes, daily notes, quick notes) already have a name.
- If you later change the first line of a note, the file name is **not** changed. Rename the file in the file tree if you want them to match.
