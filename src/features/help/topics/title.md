## Name a note by writing its title

You do not have to rename a new note.

1. Press **Ctrl/Cmd+N**, or choose **New → Note** above the file tree.
2. The note opens with the cursor after `# `. **Type the title there.**
3. A moment after you pause, the file is renamed to match. `# Weekly sync` becomes `Weekly sync.md`.

While this happens you see **Name follows title** above the note. Click it if you want to keep the current file name.

## Good to know

- Only notes you have not named yourself follow their title. If you rename a note in the file tree, Mimer never changes its name again.
- Characters a computer does not allow in file names (`: ? " < > | *` and so on) are left out.
- If a note with that name exists, a number is added: `Weekly sync 2.md`.
- Notes made from a template (meeting notes, daily notes, quick notes) already have a name and are not renamed.
- Your cursor and undo history stay as they are when the name changes.
