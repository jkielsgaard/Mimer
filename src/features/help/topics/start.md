## What Mimer is

Mimer is a notes app. Your notes are ordinary **Markdown files** (`.md`) in an ordinary folder. Mimer shows and edits them, keeps every change in a built-in **version history**, and has an assistant, also called **Mimer**, that helps you write and keep order.

## Vaults

A **vault** is the folder that holds your notes. When Mimer starts, open a folder as a vault, or create a new one. You can have several vaults and switch between them (see _Several vaults_).

## The window

- **Left:** _Files_ (your folders and notes) and _Search_.
- **Middle:** the note you are writing. Open several notes as tabs.
- **Right:** _Mimer_ (the assistant), _Images_ and _History_.
- **Bottom:** the save status, the project, the AI in use and the version of the app.

## Good to know

- You never press "save". Notes are saved a moment after you stop typing, and committed to the version history. Nothing is lost.
- Pause the mouse over a button to see what it does. A small **?** next to a setting explains it.
- Everything in this guide can be reached from the **?** button in the top bar, from **File → How to use Mimer**, or by pressing **F1**.

## Your own order

The **Sort** button above the file tree has **My own order**. Then nothing is sorted for you. Drag a note or folder to the top edge or bottom edge of another to place it before or after it, or right-click and choose **Move up / Move down** (also **Alt+Up / Alt+Down**). The middle of a folder still moves the item into the folder. The order is saved in the vault, for All files and for each project, and new notes are added last. The other sort choices, Name and Last changed, never change your order.

## Select several files

**Ctrl/Cmd+click** items in the file tree to tick them, or click one and **Shift+click** another to tick everything between. Then right-click a ticked item and choose **Move N items to…** or **Delete N items**, or drag them together onto a folder or a project. A plain click clears the selection. Deleted notes can be brought back with **File → Recover deleted notes**.

## Recent, Projects and All files

The file panel has three parts. **Recent** lists the notes you opened last (4 by default; change it in **Settings → General → Recent notes shown**, 0 hides it). **Projects** shows every project with its own notes. **All files** holds everything that is not in a project, with **Meetings** and **Quick notes** at the top.

## Found a bug, or have an idea?

Use **File → Report a bug…** or **File → Suggest a feature…**. Your browser opens a page on GitHub with the form already started (Mimer version and system filled in). You need a free GitHub account to send it. Do not paste private notes.
