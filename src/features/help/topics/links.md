## Link to another note

Click **Link to a note** in the toolbar, or press **Ctrl/Cmd+Shift+K**. A search opens over **all notes in the vault**, also in other folders and projects. Pick one and Mimer writes the link for you.

- If you had selected a word, it stays as the text of the link: `[[Budget 2026|the budget]]`.
- If two notes have the same name, the link uses the path so it goes to the right one.
- Type a name that does not exist, and Mimer offers a link to a **new note**. Clicking such a link later creates the note.

You can also type `[[` and a list of notes opens. Or drag a note from the file tree into the text.

| Link               | Means                        |
| ------------------ | ---------------------------- |
| `[[Note]]`         | link to the note called Note |
| `[[Note\|text]]`   | the same, shown as _text_    |
| `[[Note#Heading]]` | a heading in the note        |
| `[[Folder/Note]]`  | the note at that path        |

**Ctrl/Cmd+click** a link to open it.

## Index pages

Right-click a folder (or a project) and choose **Create index page**. Mimer makes a note with a link to every note in the folder and its sub-folders.

- Click **Create index page** again to refresh the list. Only the list between the two hidden marker lines is rewritten, so text you added above or below stays.
- Right-click an empty part of the file tree for an index of the whole vault.

## When you rename or move a note

Mimer asks whether to update the links in other notes. Say yes and nothing breaks.

## Tags

Write `#tag` anywhere in a note. When you type `#`, Mimer suggests the tags you already use, most used first; press Esc or keep typing to ignore it, and nothing is added unless you choose one. In the **Outline** panel you see the tags of the open note (click one to search for it) and **+ tag** to add one. In the search panel, tags with their counts are shown while the search box is empty. The AI button above a note has **Suggest a title and tags**.
