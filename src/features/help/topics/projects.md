## Projects

A **project** is a folder with its own instructions for Mimer. Use it to keep one area apart, for example a customer, a course or a work stream.

## Make one

- **New → Project…** above the file tree, or
- right-click a folder and choose **Make project**.

Then fill in:

- **Name** and **Instructions**: what Mimer should know and how it should write in this project.
- **AI provider**: use the default or choose another.
- **Local AI only**: Mimer can then only use an AI on your own computer for this project. Mimer enforces this, so no note from the project is sent to a cloud service.

A project cannot be inside another project.

## Where the project is

A project is **not** part of **All files**. It has its own tree under **Projects** at the top of the file panel:

- Click the project to open or fold it. Its notes and folders are listed below it.
- **+** next to the project makes a new note in it; the gear opens the project settings. You can also right-click inside the tree to make notes and folders.
- To move a note into a project, **drag it onto the project** (or onto a folder inside it). To take it out, drag it into All files.
- The filter box searches the projects too.

Links work across projects. A note outside any project can link to a note in a project with `[[Name]]`, and the other way round. A project only limits what **Mimer** may read and change, not your links.

## What changes

When you work in a note inside the project, Mimer follows the project's instructions and stays inside the project folder. The bottom bar shows the project, the AI in use and a lock for **Local AI only**.

The **Ask AI to change the instructions** box in the project settings lets Mimer suggest better instructions. You see the change and must accept it.
