## Keyboard shortcuts

On Mac, use **Cmd** instead of **Ctrl**.

| Shortcut                   | What it does                            |
| -------------------------- | --------------------------------------- |
| **Ctrl+N**                 | new note                                |
| **Ctrl+S**                 | save and commit the open note           |
| **Ctrl+P**                 | quick open                              |
| **Ctrl+Shift+F**           | search                                  |
| **Ctrl+Shift+K**           | link to a note                          |
| **Ctrl+K**                 | quick AI changes on the selected text   |
| **Ctrl+L**                 | go to the Mimer chat                    |
| **Ctrl+Shift+O**           | switch vault                            |
| **Ctrl+Shift+P**           | command palette: notes, skills, actions |
| **Ctrl+Shift+D**           | today's daily note                      |
| **Ctrl+Shift+H**           | history of the open note                |
| **Ctrl+W**                 | close the tab                           |
| **Ctrl+PageUp / PageDown** | previous / next tab                     |
| **Ctrl+\\**                | two notes side by side                  |
| **Ctrl+B / Ctrl+I**        | bold / italic                           |
| **Ctrl+Alt+T**             | insert a table                          |
| **Ctrl+,**                 | settings                                |
| **F1**                     | this guide                              |
| **Esc**                    | close a window or list                  |
