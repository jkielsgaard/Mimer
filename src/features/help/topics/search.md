## Find a note

- **Quick open** (**Ctrl/Cmd+P**): type part of a note's name and press Enter.
- **Search** (**Ctrl/Cmd+Shift+F**): searches the text of all notes while you type.
- The **filter box** above the file tree narrows the tree to matching names.

## Search tips

| Type               | Finds                                            |
| ------------------ | ------------------------------------------------ |
| `firewall`         | notes with the word (and words starting with it) |
| `tag:security`     | notes with the tag `#security`                   |
| `path:Work`        | only notes in the folder Work                    |
| `tag:iso password` | a tag and a word together                        |

## Search by meaning

If you have turned on **Semantic search** in **Settings → AI**, the search panel shows **Keyword**, **Meaning** and **Both**. _Meaning_ finds notes that talk about the same thing even with different words. _Both_ combines them.

It only uses an embedding model on your own computer, so no note is sent to a cloud service.
