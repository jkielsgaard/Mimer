# Ideas and capture

Ideas (lines in `Ideas.md` in the vault root, hidden from the tree, with a note indented under each) and the boxes that write something down: `CaptureBox` (one kind: Quick note, New task or New idea), `CapturePicker` (+ Task, + Idea, + Quick note in meetings, Focus and the start page) and `QuickCapture` (the window; Ctrl/Cmd+Shift+N asks T, I or N first).

- Say what, get only that: a box never asks again which kind it is.
- A task always goes into an epic the person chose (Into); Mimer never makes an Inbox by itself.
- The note being written is never changed by capturing.
